About image digests

The Digest column shows the manifest index digest — a content-addressable SHA256 hash of the image manifest list (or single manifest for single-arch images). This is the most stable way to pin an image to a specific version, regardless of tag mutability.

For DockerHub multi-arch images (e.g. docker.io/vllm/vllm-openai), the index digest covers all platforms (amd64, arm64, etc.) — it is not the same as the amd64-only platform digest. Use it with: docker pull image@sha256:<digest>

For Red Hat registry images, which are single-arch (amd64 only), the index digest and the platform digest are the same.
